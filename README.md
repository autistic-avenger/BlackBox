## Installation

### Install with Go

```bash
go install github.com/autistic-avenger/BlackBox@latest
```

Verify the installation:

```bash
blackbox
```

---

## Requirements

- Go **1.24** or later
- Windows, Linux, or macOS

---


## Building

Clone the repository:

```bash
git clone https://github.com/autistic-avenger/BlackBox.git

cd BlackBox

go build
```

Run:

```bash
./BlackBox
```
